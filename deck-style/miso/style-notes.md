# Make It So Camp — mood & discipline

**Register:** Swiss poster. Flat bone ground, heavy grotesque, hard rules,
generous space. Statements are set large and tight; nothing decorative.
The site (misocamp.com) is the reference — this pack is its deck form.

**Fonts:** Helvetica Neue throughout, no serif anywhere. Weight and size
carry hierarchy, not a second typeface. System font, so no webfont fetch —
PDF export must run on a machine that has it.

**Tracking:** display type sits tight (−0.02 to −0.03em on the site). If a
title looks loose at slide scale, tighten it rather than shrinking it.

**Accent:** terracotta (`--accent`), used only for labels, rules, and the
occasional number. Never a body colour, never a large fill.

**Rules:** the site's signature is a 2px solid ink top-rule above a block.
Prefer that over a hairline.

**Light/dark rhythm:** bone is the default ground; ink slides punctuate.
The site itself has no dark mode — the ink ground is a deliberate extension
for slide rhythm, so use it for assertions and the closing, not decoration.

**Cover:** flat bone, no gradient. The poster system doesn't bloom.
